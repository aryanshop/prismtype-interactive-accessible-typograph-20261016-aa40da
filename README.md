# PrismType: Typography & Accessibility Sandbox

PrismType is an interactive front-end developer and designer tool built to test and refine typography, color contrast ratios, and WCAG compliance in real-time across functional UI components.

## Features
- **Live Typography Controls**: Adjust font family, base font size, line height, and letter spacing dynamically.
- **Color Contrast Analyzer**: Instant WCAG 2.1 contrast ratio calculations with AA and AAA compliance badges.
- **Interactive UI Preview Stage**: Test typography and color setups directly on simulated cards, forms, and metric widgets.
- **Vision Deficiency Simulator**: Simulate color blindness modes (Protanopia, Deuteranopia, Tritanopia, and Achromatopsia) instantly.
- **CSS Variable Exporter**: Copy generated custom properties directly for production use.

## Local Run Instructions
1. Download or clone all files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser or run it via a local static server (e.g., Live Server in VS Code).

## Technology Stack
- Pure Vanilla HTML5, CSS3, and JavaScript (ES6+).
- No external frameworks, build tools, or network dependencies. Completely static and offline-ready.
